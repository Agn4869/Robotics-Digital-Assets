## First asset: UVDMS

A three-hull underwater vehicle with two four-joint manipulators and coupled two-finger grippers. This repository separates reusable robot assets from the experiments in [UVMS-DriftManip](https://github.com/Agn4869/UVMS-DriftManip).

**Included:** a self-contained URDF, reduced STL meshes, native MuJoCo models, a runnable viewer, and reproducible gallery rendering. No ROS, Isaac Sim, SolidWorks, Git LFS, or access to the original development machine is needed for the MuJoCo demo.

**Scope:** a CAD-derived mechanical model, **not a calibrated underwater digital twin**. The floating model has a real free joint but zero gravity and no fluid forces; it is not a buoyancy simulation. See the [model card](assets/uvdms/README.md) before using the model for dynamics research.

![Dual arms and coupled grippers in a stepped MuJoCo simulation](docs/images/uvdms_motion.gif)

*The animation is generated by stepping MuJoCo dynamics. It is not a real-robot recording, a trained policy, or evidence of task success. Gallery colors are presentation choices.*

## Get running

Python 3.10+ is recommended. The release is exercised with MuJoCo **3.3.7**; use the pinned requirements first.

```bash
git clone https://github.com/Agn4869/Robotics-Digital-Assets.git
cd Robotics-Digital-Assets
python -m venv .venv
```

Activate the environment:

```powershell
# Windows PowerShell
.venv\Scripts\Activate.ps1
```

```bash
# Linux / macOS
source .venv/bin/activate
```

Then:

```bash
python -m pip install -r requirements.txt
python examples/preview.py --model fixed
```

For a floating-base mechanical demonstration:

```bash
python examples/preview.py --model floating
```

For a noninteractive dynamics run without opening a viewer:

```bash
python examples/preview.py --model fixed --headless --seconds 5
```

On macOS, use `mjpython examples/preview.py --model fixed` for the interactive viewer if the platform requires MuJoCo's launcher. On a Linux machine without a display, native rendering may require a working EGL/OSMesa backend; the headless stepping command does not require rendering.

### Load directly in your own code

Run from the repository root:

```python
from pathlib import Path
import mujoco

scene = Path("assets/uvdms/mujoco/scene.xml").resolve()
model = mujoco.MjModel.from_xml_path(str(scene))
data = mujoco.MjData(model)

# The eight arm joints and two master gripper joints have position controls.
# Inspect actuator names and ctrlrange rather than assuming actuator indices.
for i in range(model.nu):
    print(mujoco.mj_id2name(model, mujoco.mjtObj.mjOBJ_ACTUATOR, i),
          model.actuator_ctrlrange[i])

for _ in range(1000):
    mujoco.mj_step(model, data)
```

Use `assets/uvdms/urdf/uvdms.urdf` in a URDF-capable tool. Its mesh paths are relative: keep the neighboring `meshes/` directory. A downstream importer must support URDF mimic joints or implement them explicitly; the supplied MuJoCo version already represents these couplings.

## What is in the repository?

| Path | Purpose |
|---|---|
| `assets/uvdms/urdf/uvdms.urdf` | Portable robot description; SI units and original joint names |
| `assets/uvdms/meshes/` | Reduced binary STL meshes shared by URDF and MuJoCo |
| `assets/uvdms/mujoco/model.xml` | Fixed-base native MuJoCo robot |
| `assets/uvdms/mujoco/scene.xml` | Fixed-base scene for inspection and manipulation prototyping |
| `assets/uvdms/mujoco/floating.xml` | Free-base, zero-gravity mechanical demonstration |
| `assets/uvdms/metadata.json` | Mesh hashes, reduction statistics, model mass and provenance |
| `assets/uvdms/physical_parameters.json` | Source-labeled physical references; not automatically applied fluid forces |
| `examples/preview.py` | Interactive viewer and headless dynamics example |
| `examples/render_gallery.py` | Render the actual shipped model into PNG/GIF previews |
| `tools/` | Optional packaging and MJCF generation tools |
| `docs/validation.json` | Measured release validation results and limitations |

## Rebuild and inspect

Ready-to-use assets are committed. You do **not** need to run conversion to use the model.

```bash
# Optional build/render tools
python -m pip install -r requirements-build.txt
python tools/build_mujoco.py
python examples/render_gallery.py
```

The original CAD export is intentionally not redistributed. To package an authorized export of your own, run `python tools/package_uvdms.py --help`; provide the source URDF and its mesh directory explicitly. Mesh reduction preserves coordinate systems and retains the source inertial parameters instead of recalculating mass from decimated surfaces.
