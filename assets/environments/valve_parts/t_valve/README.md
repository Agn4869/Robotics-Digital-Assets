# T-handle valve static part

## English

Cleaned static URDF/STL export from the supplied `T型阀.SLDPRT` export directory. This part contains one fixed link and no joint; the T-handle motion must be modeled separately in an assembly if needed.

![T-handle valve preview](../../../docs/images/environments/t_valve.png)

Mass in the exported URDF: 1.3463 kg. The mesh is retained as exported and the original SolidWorks source file is not included.
